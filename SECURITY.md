# Security

Please do not open a public issue for a suspected vulnerability, exposed credential, personal-data leak, or source-rights concern.

Use GitHub's private vulnerability-reporting feature when it is available for this repository. Otherwise, contact the repository owner through the private channel listed on the GitHub profile.

Include the affected path, a minimal reproduction, the likely impact, and whether the issue involves personal data or an active credential. Do not include real secrets or unnecessary personal information.

This portfolio repository contains representative policy code only. Production credentials, databases, and private administrative surfaces are intentionally excluded.
