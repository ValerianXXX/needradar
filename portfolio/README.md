# AI Strategy Case Deck

[Download the PowerPoint presentation](NeedRadar_AI_Strategy_Case_Study.pptx)

The nine-slide deck is designed for an AI Strategy or AI Transformation interview. It uses the same visual language as the live product: warm paper, editorial serif headlines, square rules, radar imagery, and restrained indigo, teal, amber, and coral signals.

The narrative covers:

1. the decision problem;
2. the four evidence layers;
3. the implemented pipeline and ownership boundary;
4. a verified production snapshot;
5. an illustrative specialist-OCR pilot decision;
6. the target human/AI operating model;
7. a proposed 90-day path;
8. proven and unproven claims.

Every slide has been rendered and visually inspected. Automated overflow checks passed. The deck contains no Chinese-language text.
