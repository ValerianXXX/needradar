# Governance and Decision Rights

## Principle

Automate reversible evidence preparation. Assign accountable ownership to decisions whose errors affect rights, investment, safety, or real-world outcomes.

| Decision | System / AI | Accountable person |
|---|---|---|
| Normalize and structure records | Execute and log | Review exceptions |
| Flag likely noise or PII | Recommend with reasons | Decide ambiguous cases |
| Suggest cluster membership | Score and compare | Correct disputed membership |
| Draft an opportunity | Assemble required fields | Own interpretation and priority |
| Suppress likely duplicates | Apply transparent threshold | Review strategic edge cases |
| Approve source-rights exception | Provide evidence only | Approve or reject |
| Set acceptable failure | Model scenarios | Own the threshold |
| Interpret real-task results | Summarize evidence | Decide scale, redesign, or stop |

## Primary risks and controls

| Risk | Control | Residual question |
|---|---|---|
| Personal data in public text | Automatic flag, quarantine, correction and takedown path | What false-positive rate is acceptable? |
| Unsupported source use | Policy registry and submission-only state | Which sources require renewed permission? |
| Duplicate opportunities | Weighted task and evidence comparison | What threshold best preserves meaningful distinctions? |
| Hallucinated structure | Preserve source text and mark editorial fields | Which fields require domain review? |
| False market claim | Evidence levels and portfolio claim register | What behavior would justify the next level? |
| Automation bias | Reason logs and explicit human decision rights | Where do reviewers over-trust confidence scores? |

## Audit record

A defensible decision record should contain the candidate, evidence state, policy version, similarity comparison, result, reasons, actor type, timestamp, and any later correction or withdrawal.

## Publication outcomes

- **Publish:** evidence and required fields pass; no likely duplicate exceeds the threshold.
- **Suppress:** a published brief already covers substantially the same user task and evidence.
- **Hold:** evidence is incomplete, inaccessible, unsafe, or insufficiently independent.
- **Remove:** a later source, rights, privacy, or quality review invalidates publication.
