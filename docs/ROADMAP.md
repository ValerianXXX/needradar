# Proposed 90-Day Validation Path

This roadmap is proposed and has not yet been executed.

## Days 0–30: Align and baseline

- Select one opportunity with a named workflow owner.
- Recruit five to eight representative operators.
- Observe the current task and exception paths.
- Measure time, error, rework, and handoffs.
- Define source, privacy, and acceptable-failure constraints.
- Write explicit proceed, redesign, and stop criteria.

**Decision output:** a bounded problem statement, baseline, risk register, and approved prototype scope.

## Days 31–60: Prototype and trial

- Build the smallest end-to-end flow that tests the central mechanism.
- Use held-out inputs and deliberately difficult cases.
- Preserve original evidence and model uncertainty.
- Run facilitated real-task sessions.
- Compare results with the baseline and log exceptions.

**Decision output:** evidence on feasibility, user behavior, failure modes, and workflow integration.

## Days 61–90: Adoption and value

- Run a bounded production-like pilot.
- Measure task outcomes, repeat use, and reviewer burden.
- Evaluate control effectiveness and residual risk.
- Estimate value only from observed workflow changes.
- Decide to scale, redesign, or stop.

**Decision output:** a named owner, measured baseline and outcome, observed adoption, documented risk, and explicit next investment decision.

## Minimum scorecard

| Dimension | Example measure |
|---|---|
| Decision preparation | Median time to a review-ready opportunity brief |
| Evidence quality | Reviewer agreement on evidence level and source eligibility |
| Distinctness | Precision of duplicate-suppression decisions on a labeled sample |
| Workflow outcome | Time, error, rework, or handoff reduction for the selected task |
| Adoption | Eligible users who return for a second real task |
| Governance | Exceptions, overrides, privacy events, and source-rights incidents |

The scorecard should be adapted before the pilot. Targets must be agreed by the workflow owner and control owners, not inferred from model confidence.
